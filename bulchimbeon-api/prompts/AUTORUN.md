## 2. 실행 루프

마일스톤 하나가 세션 하나다. 각 마일스톤에서:

1. **읽는다** — 해당 `prompts/*.md` + 그 안의 `@docs/...` 참조. **문서가 곧 사양이다.**
2. **구현한다** — `CLAUDE.md`의 아키텍처 규칙 9개를 지킨다.
3. **DoD를 통과시킨다** — 마일스톤 프롬프트의 완료 기준을 하나씩 확인한다. 테스트가 증거다.
4. **리뷰 패스를 돌린다** — 아래 §5.
5. **커밋한다** — `feat(M3): ...` 형태. 테스트가 깨진 채로 커밋하지 않는다.
6. **세션표를 갱신한다** — `START-HERE.md`에 `✅ 완료 YYYY-MM-DD`.
7. **보고하고 멈춘다** — 다음 마일스톤은 새 세션에서. 컨텍스트가 남아도 마일스톤 경계에서 끊는다.

한 세션에서 여러 마일스톤을 욱여넣지 마라. M3·M4는 그 자체로 한 세션이 빠듯하다.

## 3. ⭐ 반드시 질문해야 하는 상황

**자율 실행의 뜻은 "묻지 않는다"가 아니라 "물을 것과 그냥 할 것을 정확히 가른다"이다.**
아래에 해당하면 **추측하지 말고 멈춰서 물어라.** 추측으로 진행한 뒤 되돌리는 비용이 질문 한 번보다 훨씬 크다.

### 3.1 사양이 갈릴 때

- **문서 간 충돌을 발견했을 때.** 우선순위 규칙(`02` > `05` > `06` > 나머지)으로 기계적으로 해소되면
  그렇게 하고 **보고만** 한다. 하지만 우선순위로도 안 갈리거나, 우선순위대로 하면 명백히 이상한 결과가
  나오면 **묻는다.**
- **문서에 없는 설계 결정을 해야 할 때.** 예: 에러 코드 신설, 인덱스 추가, 응답 필드 추가,
  상태 전이 신설. `05-api-contract.md`는 **프론트 팀과의 계약**이므로 여기에 없는 것을 임의로 만들면
  계약 위반이다.
- **문서가 "TBD"·"추후 확정"·"미정"으로 남긴 지점**에 도달했을 때.
- **같은 것을 두 가지 방식으로 구현할 수 있고 둘 다 문서에 어긋나지 않을 때** — 어느 쪽인지 묻는다.

### 3.2 실측이 문서를 뒤집을 때

M-1에서 **세 번** 일어났다. 또 일어난다고 가정하라.

- 문서가 "X는 항상 Y다"라고 했는데 **실측이 다를 때.** (M-1 예: 부분 UNIQUE 단일 UPDATE)
- 문서가 전제한 성능·용량·버전이 **실제와 다를 때.** (M-1 예: Postgres 16 vs 18, 지연 2.3배 변동)
- 테스트가 통과하는데 **통과하면 안 될 것 같을 때**, 또는 실패하는데 **원인이 코드가 아니라 사양일 때.**

이 경우 **문서를 조용히 고치지 마라.** 실측 결과와 함께 "문서를 고칠까요, 구현을 고칠까요"를 묻는다.

### 3.3 외부·비가역·비용

- **외부 계정·키·권한이 필요할 때** (Notion 토큰, GitHub 토큰, 배포 설정 등). 직접 만들 수 없으니 요청한다.
- **되돌리기 어려운 작업** — 배포, 파괴적 마이그레이션(`DROP`/`ALTER TYPE`), 원격 푸시, PR 생성,
  DB 데이터 삭제. **실행 전에 확인받는다.**
- **실 API 호출로 비용이 발생할 때** — M3의 실LLM 스모크처럼 문서가 명시한 것은 그냥 하되,
  **반복 실행이나 대량 호출**이 필요하면 묻는다.
- `sudo`가 필요할 때 — 실행할 수 없으니 명령을 제시하고 요청한다.

### 3.4 DoD가 안 닫힐 때

- DoD 항목을 **충족할 수 없고 원인이 사양에 있을 때.**
- DoD를 통과시키려면 **문서를 고쳐야 할 때.**
- 마일스톤을 부분만 완료하고 넘어가야 할 것 같을 때 — **혼자 결정하지 마라.**

### 3.5 스코프

- 문서에 없는 기능이 **필요해 보일 때.** 필요해 보인다고 만들지 않는다.
- 문서에 있는데 **불필요해 보일 때.** 불필요해 보인다고 빼지 않는다.
- 작업량이 예상을 크게 넘어 **마일스톤을 쪼개야 할 것 같을 때.**

## 4. 질문하지 말고 그냥 할 것

물음표가 남발되면 자율 실행이 아니다. 아래는 **묻지 말고 진행한다.**

- 문서에 답이 있는 것. **묻기 전에 `docs/`를 먼저 검색하라.**
- 코드베이스를 보면 알 수 있는 것 (기존 패턴, 명명 규칙, 폴더 구조).
- 관례적 판단 — 변수명, 헬퍼 분리, 테스트 파일 배치, 타입 힌트 형태.
- 명백한 버그 수정, 오타 정정, 린트 오류 해소.
- 문서 우선순위 규칙으로 기계적으로 해소되는 충돌 (해소하고 **보고만** 한다).
- 마일스톤 프롬프트가 이미 지시한 것.

## 5. 리뷰 패스 (위임분 필수)

**작성과 리뷰를 같은 컨텍스트에서 자기 승인하지 않는다.**

- 에이전트에 위임한 마일스톤은 DoD 테스트 통과에 더해 **별도 리뷰 패스**를 거쳐야 합격이다.
- 리뷰는 `oh-my-claudecode:code-reviewer` 또는 `oh-my-claudecode:verifier`가 **diff를 읽고**
  문서 정합성(계약서·비즈니스 룰 준수)을 확인한다.
- 위임/수동 경계:
  - **수동(직접)**: M3 질문 파이프라인, M4 확인 워크플로 — 데모의 심장이고 판단이 많다.
  - **위임 가능**: M0 스캐폴딩, M2 문서 인제스트, M7 지표, M9 시드
  - **병렬 위임 후보**: M5+M6 (`07:64`가 지목한 병목), M8

## 6. 정지 조건

아래에 해당하면 **즉시 멈추고 보고한다.**

- 같은 테스트를 **3회 고쳐도** 통과하지 못할 때 — 원인 분석을 보고하고 지시를 받는다.
- 문서를 고쳐야만 진행할 수 있는데 그 변경이 **다른 마일스톤에 파급**될 때.
- `CLAUDE.md`의 아키텍처 규칙 9개 중 하나를 **어겨야만** 진행할 수 있을 때.
- 예상 작업량이 마일스톤 범위를 **명백히 초과**할 때.

## 7. 금지

- ❌ **가짜 완료** — `TODO` 주석, `test.skip`/`.only`, 빈 함수, `pass`만 있는 분기, 스텁 테스트를
  남긴 채 "완료"라고 보고하는 것. 완료 전에 변경 파일에서 이 패턴을 직접 확인한다.
- ❌ **테스트가 깨진 채 다음 마일스톤으로 넘어가기.**
- ❌ **임계값 하드코딩** — 반드시 `projects.settings`에서 로드. 기본값은 `config.py`의
  `DEFAULT_SETTINGS` **한 곳**에만 (`CLAUDE.md` 룰 3).
- ❌ **`app/services/llm/` 밖에서 openai SDK 직접 import** (룰 2).
- ❌ **실 API를 호출하는 테스트** — `FakeLLMProvider`를 쓴다. 예외는 M3 실LLM 스모크 1회뿐 (룰 2).
- ❌ **문서를 조용히 고치기** — 사양 변경은 반드시 보고·확인을 거친다.
- ❌ **`--workers 1` 이외의 설정** — SSE 큐가 인메모리, APScheduler가 중복 발화 (룰 9).
- ❌ **계약서에 없는 엔드포인트·필드·에러코드 신설** — `05`는 프론트 팀과의 계약이다.

## 8. 질문하는 방법

- **`AskUserQuestion`을 쓴다.** 산문으로 질문을 던지고 끝내지 않는다.
- **한 번에 하나.** 여러 개를 묶으면 답이 얕아진다.
- **근거를 먼저 댄다** — `파일:라인` 또는 실측 출력. "문서에 없어서요"가 아니라
  "`05:139`에 `s_floor`는 있는데 `X`가 없습니다"처럼.
- **선택지를 준다.** 2~4개. 추천이 있으면 **첫 번째에 두고 "(추천)"**을 붙이고 이유를 쓴다.
- **묻기 전에 할 수 있는 조사를 다 한다.** 코드·문서·실측으로 좁힌 뒤, 남은 진짜 결정만 묻는다.
- **질문을 기다리는 동안 놀지 않는다** — 답에 의존하지 않는 작업이 있으면 그걸 먼저 한다.

## 9. 보고 형식

마일스톤 완료 시:

```
## M{n} {이름} 완료

**DoD**: {통과 항목}/{전체} — 미충족이 있으면 항목과 이유
**테스트**: {통과}/{전체} · 커버리지 대상 {주요 경로}
**리뷰 패스**: {에이전트} — {지적 사항과 처리}
**커밋**: {sha} {메시지 첫 줄}
**문서 변경**: {있으면 파일:라인과 사유, 없으면 "없음"}
**발견**: {실측이 문서와 달랐던 점, 다음 마일스톤에 영향을 주는 것}
**다음**: M{n+1} — 새 세션에서 `@prompts/{다음}.md`
```

숫자를 부풀리지 않는다. 테스트가 깨졌으면 깨졌다고, 건너뛴 게 있으면 건너뛰었다고 그대로 쓴다.
