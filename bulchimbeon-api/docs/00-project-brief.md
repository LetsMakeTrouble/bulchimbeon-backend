# 00. 프로젝트 브리프 — 불침번 (Bulchimbeon)

> **당신이 자는 동안, 협업은 계속된다.**
> 시차가 큰 글로벌 팀에서 담당자가 부재 중이어도, 프로젝트 문서와 승인된 지식을 근거로
> AI가 **즉답 / 확인 대기 / 보류**로 정직하게 분기해 답한다.

---

## 1. 제품 정의

- **서비스명**: 불침번 (가칭)
- **형태**: 비동기 Q&A 협업 웹앱 — **이번 구현 범위는 백엔드 API 서버 전체** (프론트엔드는 별도 팀이 API 계약서를 받아 개발)
- **목표**: 질문-확정-재사용의 폐쇄 루프를 완성해 시차로 인한 대기시간과 재작업을 줄인다.

## 2. 해결하는 문제

### 질문자(한국) 측
- 질문 하나 + 되물음 하나 = 2일 소요 ("24시간 핑퐁")
- 답을 기다리는 동안 작업이 막히거나, 추측으로 진행해 재작업 발생
- 영어 문서가 있어도 확신이 없어 결국 다시 물어봄

### 담당자(영어권) 측
- 반복 질문에 매번 응답해야 하는 부담
- 퇴근 후에도 노트북을 놓지 못하는 상시 대기 스트레스

### 핵심 통찰
시차로 막히는 질문의 70~80%는 답이 이미 존재한다(문서·과거 대화 속에).
사람이 자는 건 어쩔 수 없지만, 협업이 멈출 필요는 없다.

## 3. 핵심 컨셉 (4개)

1. **신뢰등급 3분기** — 모든 답변에 매칭률(근거 충족도, 0~100)을 계산해
   🟢 즉답(80↑) / 🟡 확인 대기(50~79) / 🔴 보류(50 미만)로 분기. 근거 없으면 지어내지 않고 사람에게 넘긴다.
2. **참고 → 확정 상태 모델** — 모든 AI 답변은 "근거 딸린 참고자료"로 시작하고,
   담당자 승인·수정으로만 확정된다. 질문자는 ✅맞았다/❌달랐다 크로스체크로 검증에 참여한다.
3. **다국어 비대칭 처리** — 질문자는 한국어, 지식·담당자는 영어. 담당자에게 넘어가는 질문은
   영어로 번역해 배경→질문→선택지로 구조화한다.
4. **지식 환류 루프** — 확정 답변은 공식 Q&A로 편입되어 재사용되고(같은 질문에 두 번 다시
   24시간이 걸리지 않음), 담당자 수정에서 교훈을 추출해 이후 답변 품질을 키운다.

## 4. 타겟 · 대표 시나리오

**대표 페르소나**: 한국 제품팀 질문자(지수) ↔ 영어권 개발 파트너 담당자(마이크), API 명세 확인 상황.

- **시나리오 A (빠름)**: 지수가 한국어로 "주문 조회 API 응답에 user_id 포함되나요?"라고 질문
  → 시스템이 영어 명세에서 근거를 찾아 🟢 즉답 + 매칭률 + 인용 + 근거 원문 제공.
- **시나리오 B (정직함과 진화)**: 특정 리전 정책 질문에 문서가 부족/충돌
  → 🔴 보류 + 누락·충돌 근거 제시 → 담당자 확인 카드 큐로 전달 → 담당자가 수정/승인
  → 질문자에게 한국어 정정 알림 → 공식 Q&A로 저장 → 후속 유사 질문에서 즉시 재사용.

## 5. 성공 지표

| 지표 | 정의 | 목표 |
| --- | --- | --- |
| 등급 확정 시간 | 질문 접수부터 등급 확정(답변 발행 or 보류 확정)까지 | 20초 이내 (⚠️ M-1 캘리브레이션 실측 후 확정 — `06 §0`) |
| 근거 지원률 | 🟢 답변의 핵심 주장 대비 인용 지원 비율 | 90% 이상 |
| 보류 재현율 | 충돌/정보없음 질문을 🔴로 잡아내는 비율 | 90% 이상 |
| 자동응답률 | 전체 질문 중 🟢+🟡 비율 | 70% 이상 |
| 정정률 | 크로스체크 중 "달랐다" 비율 | 10% 이하 |
| 카드 처리 시간 | 카드 열람부터 담당자 액션까지 30초 내 비율 | 80% 이상 |
| 재질문 즉답률 | 확정 답변이 있는 질문이 다시 왔을 때 바로 답한 비율 | 95% 이상 |
